# 01 意图解码

目的：把一句模糊需求压成一张可执行的意图卡，让后面的建模没有歧义空间。

## 意图卡七字段的填写规范

### 1. 对象
必须写到「可建模的粒度」。判错品类的代价最大。

- 弱：`一辆车` / `一个东西` / `这个产品`
- 强：`双门纯电轿跑，溜背式车顶，无格栅前脸，隐藏式门把手`

判断方法：问自己「只凭这句话，另一个工程师能不能画出主轮廓」。不能，就继续细。
用用户的词优先（用户说「小电驴」就不要擅自升级成「电动踏板车」），但内部建模用规范名称，界面文案用用户的词。

### 2. 目的（决定一切取舍）
| 目的 | 优先呈现 | 必须舍弃 |
| --- | --- | --- |
| 看懂结构 | 部件分层、爆炸、剖切 | 材质真实感、环境氛围 |
| 看懂流程 | 时序、方向、节拍 | 单件细节、静态美感 |
| 选型对比 | 尺寸差异、关键参数 | 装饰、故事性 |
| 展示质感 | 材质、光照、运镜 | 内部结构、参数 |
| 教学讲解 | 标注、分步、术语解释 | 炫技、复杂运镜 |
| 单纯氛围 | 构图、光、色 | 工程准确性（但要声明是示意） |

**一个页面只能有一个主目的。** 用户说要「既能看结构又能感受质感」时，选主目的，把另一个降级为可选视图。

### 3. 受众
决定术语密度与标注深度，不是决定配色。

- 外行：不用行业缩写，给类比（「这个部件相当于刹车」），标注少而准。
- 有基础：用规范术语，标注指向关键结构。
- 专业：给尺寸、材料牌号、工序名称、公差量级（若已知）。

不确定受众时按「有基础」处理，并保留可展开的说明层。

### 4. 尺度
这是最容易被忽略、又最影响可信度的字段。

- 有真实尺寸 → 写进场景单位（建议 1 单位 = 1 米），全部构件按真实比例。
- 无尺寸 → 用可参照物定标：A4 纸 297mm、成年人 1.7m、手掌 180mm、易拉罐 66mm。
- 完全不可知 → 声明「示意比例」，并在画面里放一个尺度参照物（人或标尺）。

判定红线：物体最长尺寸与场景里最薄构件的比值，如果小于 20:1，说明你的尺寸表里必然有错。

### 5. 必须出现的要素
用户点名的部件、工序、数据，逐条列出，作为验收硬指标。用户没说但缺了会显得外行的，补进「应当出现」。

### 6. 可以舍弃的要素
主动写。这是后面性能降级的合法依据，也避免 P4 阶段被细节拖死。

优先级排序（舍弃从低到高）：
1. 不可见内部结构
2. 微小纹理细节（螺丝、缝线、铭牌文字）
3. 背景环境
4. 次要部件（线缆、支架、标签）
5. 材质次级通道（法线细节、AO 微变化）

### 7. 交付形态
| 形态 | 适用 | 技术含义 |
| --- | --- | --- |
| 单页展示 | 产品、单物体 | 固定机位 + 限位轨道 + 可选自动运镜 |
| 分步动画 | 装配、流程、原理 | 时间轴 + 状态机，必须有暂停与重播 |
| 可交互探索 | 结构复杂、科学结构 | 热点、爆炸、剖切、切换 |
| 多页 | 产线全流程、课程 | 页内视图切换，共享渲染器 |

## 模糊需求降维法

用户常见表达 → 应立即解码为可建模问题：

| 用户说 | 真实需求 | 你的动作 |
| --- | --- | --- |
| 「做得高级一点」 | 光照与材质可信度不足 | 补三光、IBL、接触阴影，不动几何 |
| 「科技感」 | 冷色 + 精准线条 + 少量发光 | 克制：细边缘光 + 深色基座 + 单一发光语义 |
| 「像苹果官网那样」 | 大留白、单主体、慢速运镜、柔和 studio 光 | 换构图与光，不是换配色 |
| 「能动起来」 | 想要状态变化 | 编一个有语义的动作段落，不做匀速自转 |
| 「要真实」 | 尺寸与材质要站得住 | 定真实尺度表 + 五通道一致的材质 |
| 「要酷」 | 不确定 | 反问或选一个明确方向（例如「做剖面透视」），不要堆特效 |

## 提问协议

**默认不问。** 只在下列情况问，且一次问完，最多 3 个：

1. 品类判不准（会整体返工）。
2. 尺度差一个数量级（会毁掉所有比例判断）。
3. 用户明确要求「按我说的做」但关键要素缺失（不补会交付错东西）。

提问形式：给出你的默认判断 + 选项，让用户点头而不是让用户写作文。

> 「我按 A 假设做（大约 1.2 米高，不锈钢主体）；如果你要的是 B（桌面小件），告诉我，我改尺度表。」

不要问「你想要什么风格」这类无法回答的问题。要问「要不要把内部结构做成可展开的剖切视图」。

```
受众：……

交付形态：……
精度档：L1（面数 3k–30k，绘制调用 <80）

参考等级：R2（3 张不同角度照片）
推断清单：背面走线按对称性原则补；内部腔体按功能约束（进料口→腔体→出料口）补
```
