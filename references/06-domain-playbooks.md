# 06 领域剧本

每个剧本给：**这类对象的关键结构**、**必须出现的要素**、**算法组合**、**最容易翻车的点**。按对象类型选剧本，不要混用。

## 1. 产品（消费电子、家电、日用品）
- **关键结构**：外壳（含分缝与倒角）、屏幕/面板、按键/接口、品牌标。
- **必出现**：真实比例、材质对比（金属框 vs 玻璃面 vs 塑料底）、干净的 studio 光。
- **算法**：A1 图元 + A3 放样（弧面后盖）+ B1/B3（PBR + IBL）+ D2 限位轨道。
- **翻车点**：全网一个灰色材质；屏幕用自发光贴图乱画 UI；倒角全靠布尔导致破面。
- **加分**：分缝用细凹槽（不是画线），按键有 0.5mm 的压下行程。

## 2. 汽车 / 交通工具
- **关键结构**：主车身（长条体）、车顶弧（曲线）、轮（圆）、灯组、格栅、门缝。
- **必出现**：侧视比例（车长/车高 ≈ 3:1）、轮距、A/B/C 柱走向、地面接触阴影。
- **算法**：A2 Catmull-Rom 描侧视轮廓 → A3 放样出体；A1 轮；B3 环境反射（车漆靠反射，不靠高光）。
- **翻车点**：车身像一块被切过的方块；轮子尺寸不合比例；车漆用纯色不加反射 → 读成塑料玩具。
- **加分**：车漆用 `MeshPhysicalMaterial` 的 `clearcoat`，配一条环境反射带（长条形柔光箱），这是车图的灵魂。

## 3. 机械 / 机构
- **关键结构**：基座、驱动（电机/齿轮）、传动（连杆/皮带/凸轮）、执行端、紧固件。
- **必出现**：动力传递链完整（能看出从哪进、怎么传、最后动哪里）、运动副（转动/移动）、润滑/防护件可省但要声明。
- **算法**：A1 + A4（打孔开槽，≤5 次）+ C7 机构运动学 + D3 爆炸/剖切。
- **翻车点**：只做一个不动的摆件；连杆机构运动学解错导致穿模；齿轮转向反了。
- **加分**：把「输入角速度 → 输出位移」做成可调滑块，让人自己摇，比播动画更有说服力。

## 4. 工业产线 / 工艺流程（重点）
工业题材的胜负手是**信息**，不是模型精度。

- **关键结构**：上料 → 加工工位（多台）→ 检测 → 装配 → 下料/包装；中间有缓存区、AGV/传送带、机械手。
- **必出现**：① 真实布局比例（通道 ≥0.8m、设备间距）② 工序顺序 ③ 节拍与瓶颈 ④ 物料流向 ⑤ 人物尺度锚 ⑥ 工位负荷标注。
- **算法**：E1 节拍模型计算瓶颈 → E2 甘特叠加 → C6 弧长路径跟随物料 → E5 数据着色（负荷/OEE）→ F1 实例化重复工位。
- **叙事结构（推荐）**：
  1. 全景俯视：整线布局 + 流向箭头
  2. 拉近瓶颈工位：负荷条 + 为什么堵
  3. 单件视角：物料从 A 到 B 的完整路径
  4. 对比：优化前后节拍差
- **翻车点**：把产线做成「一排漂亮的机器」却没有流程信息；比例失调导致看起来像玩具工厂；动画一直在动但看不出谁快谁慢。
- **加分**：给一个「节拍滑块」，调需求产量 → 瓶颈工位变色、产出数字实时变。这一步就把静态模型变成了分析工具。

## 5. 建筑 / 空间 / 场景
- **关键结构**：体量、开窗、屋顶、场地（道路/绿化/水）。
- **必出现**：尺度锚（人、车、门高 2.1m）、朝向（光照方向决定时间感）、地平线。
- **算法**：A9 形状语法快速生成体量 → F4 合批 + F2 LOD → B4 阴影（太阳角度）。
- **翻车点**：没有人的尺度，楼像模型玩具；窗户贴图分辨率与距离不匹配（摩尔纹）。
- **加分**：太阳角度对应一个具体时刻（如「9 月的上午 9 点」），影子方向和长度都对，专业感立刻出来。

## 6. 科学 / 医学结构
- **关键结构**（按对象）：分子（球棍/空间填充）、细胞（膜/核/细胞器）、器官（分层）、地质（地层/断层）、天体（尺度悬殊）。
- **必出现**：**尺度声明必须显性**（「此图非等比例」或「1 单位 = 1 Å」），否则一定是错的；标注指向准确。
- **算法**：A6 Marching Cubes（等值面）+ A7 Voronoi（细胞）+ A1 球棍 + D4 标注。
- **翻车点**：电子云做成实心球；细胞器比例失真；颜色随便用（科学可视化里颜色通常有约定：氧红、氮蓝）。
- **加分**：给「剖开/半透明」切换，让人能看到内部层次——这是科学讲解最需要的能力。

## 7. 生物 / 角色 / 有机体（含动画角色）
- **关键结构**：体块（头/胸/骨盆）、关节链、末端（手/足/尾）、表面（毛/鳞/皮肤）。
- **必出现**：剪影辨识度、重心与站姿、关节弯曲方向正确。
- **算法**：A5 细分（圆润）+ C3 IK（姿态）+ C4 布料（衣物）+ B2 程序化皮肤。
- **翻车点**：关节反折（膝反关节）；眼睛无高光；皮肤全场景一个粗糙度 → 蜡像感。
- **加分**：用一个「姿态预设」切换（站立/行走/坐），比让它原地转圈有用。

## 8. 抽象 / 品牌 / 概念
- **关键结构**：几何母题（一个重复的形）、节奏（大小/密度递变）、材质隐喻。
- **必出现**：一个明确的视觉母题 + 一致的材质语言（不要一场景三种质感）。
- **算法**：A9 L-System / A7 Voronoi / A10 噪声置换 / F5 GPU 粒子。
- **翻车点**：深蓝紫渐变 + 星空 + 悬浮粒子 + 霓虹线框 —— 「反 slop」清单里的五件套凑齐。
- **加分**：让抽象形与用户业务有解释关系（例如物流公司用「流」的走向），并在图例里说一句。

## 9. 教学 / 原理讲解
- **关键结构**：被讲解的对象 + 状态对比（前/后、通/断、正确/错误）。
- **必出现**：分步（不是一次性给完）、每步一句解释、可暂停、可回退。
- **算法**：C2 状态机 + D3 剖切 + D4 标注 + C1 缓动。
- **翻车点**：一上来全貌旋转，什么也没讲清；术语不解释。
- **加分**：错误状态用「半透明幽灵 + 红色警示」对照正确状态，是最省力的讲解法。

## 10. 动画分镜 / 演示片
- **关键结构**：镜头列表（每镜一个目的）、主体动作、转场。
- **必出现**：段落节奏（起-承-转-合）、每镜一个明确信息、镜头之间不重复。
- **算法**：C1 缓动 + C2 编排 + 相机关键帧 + B6 单次色彩管理。
- **翻车点**：相机永远在缓慢漂移（观者无法定位）；每镜都是同一个角度。
- **加分**：给一个「时间轴拖动条」，让人自己拖到任意时刻看——比自动播放更适合讲解。
