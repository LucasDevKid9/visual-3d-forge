# 02 参考解构

目的：把「一张图」变成「一张可计算的表」。这一步做不对，后面全是错的比例。

## 解构的五个动作（顺序不可乱）

```
A 轮廓分解 → B 比例标定 → C 拓扑推断 → D 材质反推 → E 不确定登记
```

### A 轮廓分解：把整体切成部件

1. **找分割线**：材质变化处、颜色断层、结构转折、接缝、阴影分界，都是部件边界。
2. **找对称轴**：绝大多数人造物有 1–3 个对称面。先定对称面，能用一半推另一半。
3. **找重复单元**：一排螺栓、一组散热片、一层层踏板。数出一个单元，其余用实例化。
4. **命名**：每个部件给一个人能读懂的名字（`前保险杠`、`散热片组`、`第三级齿轮`），不要用 `part1`。名字是后面标注系统、爆炸视图、交互热点的挂载点。

输出：**构件树**（三级足够）

```
整机
├─ 外壳组
│  ├─ 前脸（含格栅、灯组）
│  └─ 侧围（含门、把手、后视镜）
├─ ��构组
│  ├─ 底盘
│  └─ 悬架（重复单元 ×4）
└─ 功能组
   └─ 电池包（半透需剖切可见）
```

### B 比例标定：把像素换成毫米

三种方法，按可用性选：

1. **已知尺寸锚定**：图上有任何已知尺寸（标注、标准件如螺丝 M6、A4 纸、硬币、人），用它的像素长度换算全局比例尺。这是最可靠的方法。
2. **多视图三角化**：≥2 个正交视角（正视图 + 侧视图 + 俯视图任二）时，用同一特征点在两图中的像素坐标反推深度。简化做法：把正视图宽度当 X、侧视图宽度当 Z、俯视图深度当 Y，三图共有特征的像素比应一致；不一致说明有透视畸变，取图中畸变最小的一段做标定。
3. **类别先验**：无任何参照时，用同类物品的典型尺寸（轿车 4.7m 长、马克杯 95mm 高、笔记本 14 寸 320mm 宽）。必须声明这是估计。

**畸变校正**：手机拍的照片一定带透视。近大远小会让「长度」比实际短。判断方法：同一物体的平行边在图中不平行、圆形变椭圆，就说明有透视，优先用远距离拍的那张（视角越正越准）。

比例尺写成一个常数，代码里所有尺寸从它派生：

```js
const S = 0.0012; // 1px = 1.2mm（由 A4 纸 297mm / 248px 标定）
const mm = px => px * S; // 之后写 mm(320) 而不是 0.384
```

### C 拓扑推断：看不见的部分怎么补

三条补全原则，按优先级用：

1. **对称性原则**：有对称面的物体，背面 = 正面的镜像。这是最低风险补全。
2. **功能约束原则**：由功能反推结构。有进料口就必有腔体，有腔体就必有出料口；有转轴就必有轴承位；有螺丝孔就必有配合面。功能链完整，结构就合理。
3. **最小惊讶原则**：同类物体的默认形态。不要在没有证据的地方发明设计（不要在光滑曲面中间加一条缝）。

**禁止**：凭空加装饰、加发光条、加「未来感」纹路来填补信息空白。空白就是空白，宁可留白也不要造假。

### D 材质反推：从成因到参数

先回答四个问题，再填参数：

1. 这块表面**是什么材料**？（ABS 塑料 / 阳极氧化铝 / 冷轧钢 / 玻璃 / 皮革 / 陶瓷）
2. 它**经历过什么**？（机加工留下同心刀纹 / 压铸留下皮纹 / 长期摩擦抛光 / 户外氧化）
3. 它**现在处于什么环境**？（室内洁净 / 户外多尘 / 潮湿 / 高温）
4. 它**磨损在哪里**？（棱角、接触面、常用手部位）

然后用这张对照表落到参数：

| 材料 | metalness | roughness | 备注 |
| --- | --- | --- | --- |
| ABS/PC 塑料 | 0 | 0.35–0.55 | 有轻微皮纹法线；不要 0.5 万能值 |
| 阳极氧化铝 | 1 | 0.25–0.45 | 颜色来自氧化层，不是金属色 |
| 拉丝不锈钢 | 1 | 0.15–0.3 | 有方向性法线（拉丝方向） |
| 冷轧钢+喷漆 | 0 | 0.5–0.7 | 漆面下若有金属露底，需分区 |
| 玻璃 | 0 | 0.02–0.1 | 实体感来自厚度与折射，不是 opacity |
| 皮革 | 0 | 0.4–0.7 | 法线承载粒面，粗糙度随弯折变化 |
| 陶瓷 | 0 | 0.05–0.2 | 边缘有细微透光才可信 |

**关键约束**：五个通道必须描述同一块表面。凹处积灰 → 更粗糙且更暗；凸处磨损 → 更光滑且金属裸露。粗糙度的空间变化必须由第 2 问的成因推出，不能各挂一份互不相关的噪声。

### E 不确定登记：把猜测显性化

建一个清单，每条写：`部件 | 不确定项 | 采用的假设 | 依据 | 风险`。

交付时这份清单要转成一句人话（「背面走线和内部腔体是按对称性和功能约束推断的，非原图信息」）。这是可信度的体现，不是减分项。

## 参考源的具体处理

### 设计稿/渲染图（R1–R2）
信息最全但常常「假透视」（正交相机渲染）。可以直接按比例建模，注意别把渲染的柔和边缘当成真实倒角。

### 三视图/工程图（R1）
直接读尺寸标注，注意区分外形尺寸与安装尺寸。隐藏线（虚线）是内部结构，优先采信。这类参考可以做到接近工程精度，但仍需声明未做公差。

### 实物照片（R3）
按 A→E 走完，重点做畸变校正与对称补全。永远不要声称背面「与原物一致」。

### 草图/线稿（R4）
草图表达的是**设计意图**而不是成品。要读出「他想强调什么」：加粗的线是主轮廓，反复描的圆是重要特征。体积信息全部靠推断，此时应主动降低精度档（L1 或 L0）并告知用户。

### 3D 模型文件（.glb/.gltf/.obj/.stl）
最优路径：直接用 `GLTFLoader` 加载，不重建。此时你的工作是管线工作——归一化尺度、重算切线、修正材质、加环境与相机、必要时做减面（QEM）。注意：模型可能自带材质但缺光照，别把「材质没问题」当成「画面没问题」。

### 爆炸图/装配图
这是最好的结构参考：部件层级、装配顺序、数量都直接给出。优先用它构建构件树和爆炸动画的时间轴。

### 纯文字（R5）
只做结构性还原：类别先验 + 功能约束。精度档默认 L0，并在页面上标注「示意」。

## 常见错误

1. **拿渲染图的透视当真实透视**：比例整体压扁。
2. **跳过对称性**：正面做得很细，转到背面是空的。
3. **只读颜色不读成因**：所有东西都变成「灰白塑料」。
4. **把分辨率当细节**：图很清晰不代表细节该建模，微小纹理该用贴图或省略。
5. **把参考图里的环境光当物体属性**：照片里的暖色是灯光，不是材质。
