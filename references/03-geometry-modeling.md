# 03 几何建模策略

目的：为构件树里的每个部件选定一个**构造方式**，并给出代码可执行的参数来源。

## 五类构造方式

### 1. 参数化图元（Primitive Parametric）
适合：有明确功能形状的构件（机箱、底座、法兰、台阶、支架）。

用 `BoxGeometry` / `CylinderGeometry` / `SphereGeometry` / `CapsuleGeometry` / `TorusGeometry` / `ExtrudeGeometry` 直接生成，尺寸全部来自尺度表。

要点：
- 用 `widthSegments` 控制圆滑度，不要默认 1 段（大球会很方）。
- 需要真实壁厚就用「外壳 + 内壳反法线」或 CSG，不要用单面 + 双面渲染伪装。
- 一个部件由多个图元组成时，用 `Group` 承载，命名 `g. 名称`，方便后续拾取与爆炸。

### 2. 扫掠与放样（Sweep / Loft / Lathe）
适合：有截面规律的形体——车顶弧线、座椅靠背、船体、花瓶、管道、轨道、型材。

| 方法 | 用途 | 实现 |
| --- | --- | --- |
| `LatheGeometry` | 旋转对称体（花瓶、灯罩、瓶罐、餐具） | 给一条 2D 轮廓（右手侧剖面），绕轴旋转 |
| `ExtrudeGeometry` | 恒定截面沿直线拉伸（型材、板材、铭牌） | 给 2D 轮廓 + 深度 + 倒角 |
| 沿曲线扫掠 | 变截面弯曲体（管道、线缆、扶手） | 自己实现：沿 Curve3 采样点，用 Frenet 框架摆截面 |
| 放样（Loft） | 多个截面渐变（车身、鞋楦、叶片） | 给 2–N 条截面轮廓，按弧长参数插值后缝成网格 |

**曲率质量要点**：截面点数 ≥ 12，路径采样 ≥ 64，否则曲面会出现棱线。同时末端要封口，不要留开放洞（除非是有意做单面壳）。

### 3. CSG 布尔（构造实体几何）
适合：打孔、开槽、挖腔、切割、倒角替代。

实现选择：
- 优先用 three.js 官方 `three/addons/geometries/` 外的成熟库（如 `three-bvh-csg`）——固定版本引入。
- 没有库时用简化手段：**遮挡法**（把孔做成深色内衬 + 内侧圆环），视觉上成立且零成本。这是网页级常用取舍。
- 复杂度警告：多次布尔会让面数爆炸且产生退化三角形。**布尔次数控制在 5 次以内**，超过就换构造方式。

### 4. 细分曲面（Subdivision）
适合：有机形体、圆润外壳、需要高光顺滑过渡的产品。

- `Catmull-Clark`：四边形网格友好，产品外壳首选。先用少量控制点搭骨架，再细分 2 次。
- `Loop`：三角形网格友好，生物/地形用。
- three.js 自带 `SubdivisionModifier`（在 addons 里），能跑就用；对拓扑有洞的网格会失败，先补洞。

**替代方案**：控制点足够多时，用 `CatmullRomCurve3` 生成平滑轮廓直接建模，比细分更可控。

### 5. 曲面重建（从点云/高度场出发）
适合：地形、扫描件、科学数据（分子表面、流体、断层）。

| 算法 | 输入 | 输出 | 用在哪 |
| --- | --- | --- | --- |
| Marching Cubes | 3D 标量场（SDF/密度） | 三角网格 | 医学、地形、隐式曲面 |
| Dual Contouring | 同上 | 更锐利的网格 | 需要保留棱角的扫描件 |
| Delaunay 三角化 | 2D/3D 点集 | 三角网格 | 地形取样、点云铺面 |
| 高度场 → 网格 | 灰度/深度图 | 起伏面 | 地形、浮雕、布料褶皱 |

**网页级现实约束**：Marching Cubes 在 JS 里跑 256³ 网格要几百毫秒，必须放在 `requestIdleCallback` 或 Web Worker 里，并先给占位形体。

## 六类「不可见部分」的补全规则

1. **对称补全**：有对称面就直接镜像，零风险。
2. **功能补全**：由功能链反推（入口→腔体→出口、轴→轴承、孔→配合面）。
3. **遮蔽补全**：永远看不到的部分（埋在内部、被地面挡住），用最简几何（一个 Box）占位，不做细节。
4. **重复补全**：一排相同单元，只做一个，其余实例化。
5. **简化补全**：远看才可见的部件，用低模 + 正确剪影。
6. **诚实留白**：完全无依据时不做，用剪影或线框示意，并在标注里写「示意」。

## 几何策略表（P2 的产物）

每个部件一行，五列必填：

| 部件 | 构造方式 | 参数来源 | 面数估计 | 退化处理 |
| --- | --- | --- | --- | --- |
| 外壳 | Extrude + 倒角 | 尺度表 W620/H480/D180 | 1.2k | 侧壁细分不足时加 bevelSegments |
| 灯罩 | LatheGeometry | 剖面 12 点 | 0.4k | 末端开口需封口 |
| 散热片组 | Instancing ×32 | 单件 12×90×0.8 | 32×24 | 近距离才显示，远距离降到 8 片 |
| 电池包 | Box + 半透材质 | 尺度表 1100×600×120 | 12 | 需要剖切时用 clippingPlanes |

**验收**：表里不能有「待定」。写不出构造方式的部件，说明 P1 的构件树还不够细，回去重拆。

## 精度档与几何手段的对应

| 档 | 可用手段 | 禁用手段 |
| --- | --- | --- |
| L0 | 图元、剪影、单色材质 | 细分、布尔、法线贴图 |
| L1 | 图元 + 扫掠 + 少量倒角 | 多次布尔、点云重建 |
| L2 | 全部手段 + 程序化贴图 | 无节制实例化 |
| L3 | 全部 + 合批 + LOD | 单文件直出（需分帧构建） |

## 建模的四个硬纪律

1. **先包络后细节**：先把整体包围盒做对，再往里填。比例错了，细节再美也没用。
2. **先剪影后表面**：从任意角度看剪影都能认出是什么，才算形体成立。
3. **命名即结构**：`Group` 命名与构件树一一对应。没有名字的 mesh 不允许存在。
4. **参数来自表**：所有尺寸从尺度表派生（`mm(x)`），禁止在代码里散落魔法数字。改一个比例尺，全物体同步缩放。

## 代码组织（写在 HTML 内）

```js
// 尺度表
const S = { // 单位 mm
  W: 620, H: 480, D: 180, wall: 2.5, finPitch: 12
};
const mm = v => v / 1000; // 转米

// 构件树
const root = new THREE.Group(); root.name = '整机';

function buildShell() {
  const g = new THREE.Group(); g.name = '外壳组';
  const body = new THREE.Mesh(
    new THREE.BoxGeometry(mm(S.W), mm(S.H), mm(S.D)),
    mat.anodizedAlu
  );
  body.name = '主体'; body.castShadow = body.receiveShadow = true;
  g.add(body);
  return g;
}

root.add(buildShell());
```

树形结构让爆炸视图、拾取高亮、标注挂点都能一次拿到父子关系，不需要全局遍历找对象。
