## A 几何构造

### A1 参数化图元
**用在哪**：功能构件、机箱、底座、法兰、支架、台阶。
**要点**：所有参数来自尺度表；圆角一律用 `BoxGeometry` + 倒角替代（小倒角用 `CylinderGeometry` 拼角太贵）。
**失效**：需要真实圆角过渡时改用 `ExtrudeGeometry` 的 `bevelSegments`。复杂度 O(顶点)。

### A2 曲线（Bezier / Catmull-Rom / B-spline / NURBS）
**用在哪**：主轮廓线、车顶弧、扶手、轨道、任意平滑路径。
- Bezier：两端控制，适合「起止切线确定」的形状。
- Catmull-Rom：穿过所有控制点，适合「照着参考图描点」——**参考图重建首选**。
- B-spline/NURBS：控制点不插值、局部修改，适合工程曲面；JS 里通常用 B-spline 近似即可。

```js
// Catmull-Rom：直接把图上的轮廓点串成平滑曲线
const curve = new THREE.CatmullRomCurve3(pts, false, 'centripetal');
```
**要点**：`centripetal` 参数化能避免尖点和自交；点太少会失去曲率信息，一般每 30–50mm 一个点。
**失效**：曲线段数不足会出棱。采样 `curve.getPoints(200)` 再建几何。

### A3 扫掠与放样
**用在哪**：管道、线缆、型材、变截面车身、叶片、鞋楦。
- 恒定截面沿直线 → `ExtrudeGeometry`。
- 恒定截面沿曲线 → 取样点 + Frenet 框架摆截面。
- 变截面 → 多截面按弧长插值再缝合。

```js
// 沿曲线扫掠的核心：每步用切线构造局部坐标系
for (i of N) {
  const p = curve.getPointAt(i / N);           // 弧长参数化，密度均匀
  const t = curve.getTangentAt(i / N);
  const n = up.clone().cross(t).normalize();    // 副法线
  const b = t.clone().cross(n);                 // 法线
  ring[i] = place(profile, p, n, b, scaleAt(i)); // 摆截面并按需缩放
}
```
**要点**：必须用 `getPointAt`（弧长）而不是 `getPoint`（参数），否则弯曲处截面会挤在一起。
**失效**：Frenet 框架在直线段退化（切线不变导致翻转）→ 用 `up` 向量锁定的 parallel transport 方法。

### A4 CSG 布尔
**用在哪**：开孔、开槽、挖腔、切割、真实倒角。
**要点**：
- 布尔次数 ≤ 5，每次都会新增退化三角形。
- 运算前把两个网格的变换烘进几何（`geometry.applyMatrix4`），否则结果错位。
- 布尔结果必须 `computeVertexNormals()` 重算法线，否则接缝是黑线。
**失效**：面数爆炸或结果破面 → 改用**遮挡法**（孔内加深色内衬 + 内圈），视觉成立、成本为 0。

### A5 细分曲面
**用在哪**：圆润外壳、有机形体、需要连续高光的产品面。
- Catmull-Clark：四边形网格；每轮面数 ×4，控制点少时用 2 轮。
- Loop：三角网格；生物/地形用。
**要点**：细分前必须处理非流形边和洞，否则边界会撕裂。
**失效**：`SubdivisionModifier` 报错 → 改手写 CatmullRomCurve3 轮廓直接建模（更可控）。

### A6 曲面重建
**用在哪**：地形、扫描件、SDF 隐式曲面、医学/科学数据、分子表面。
- Marching Cubes：3D 标量场 → 等值面三角网格。
- Dual Contouring：保留锐边，适合带棱角的扫描件。
- 高度场 → 网格：灰度/深度图当 Y，最快的起伏面方案。

```js
// Marching Cubes 的现实约束
// 64³ 网格 ≈ 26 万体素：一次性做完约 100–300ms，必须分帧或进 Worker
// 128³ 以上不要在主线程做，先给低模占位，后台算完再替换
```
**失效**：卡死 → 降分辨率（先用 32³ 出剪影）、进 Worker、或改用高度场。

### A7 Delaunay / Voronoi
**用在哪**：蜂窝结构、晶格、破碎效果、不规则铺面、点云铺地。
- Delaunay：点集 → 三角网，最小角最大化，适合地形与铺面。
- Voronoi：Delaunay 的对偶，每个点一个胞腔，适合「碎片/晶粒/表皮」。

```js
// 二维 Delaunay（增量插入）复杂度 O(n log n) 期望
// Voronoi 胞腔 = 每个种子点的最近点区域；着色时按胞腔给不同粗糙度就是「晶粒」
```
**要点**：点数控制在 200 以内，否则三角化 + 网格构建会拖慢首帧。
**失效**：三点共线导致退化 → 加 ε 抖动（0.1% 尺寸）打破共线。

### A8 凸包 / QEM 简化 / 法线融合
**用在哪**：碰撞体、低模代理、导入模型减面、法线平滑。
- 凸包（QuickHull）：给复杂件做一个便宜碰撞体。
- QEM 边折叠：减面同时保形，导入高模时压到预算内。
- 法线融合：平滑组，避免硬边黑线。
**要点**：减面到 70% 以内肉眼难辨；到 30% 以下剪影开始塌。
**失效**：减面后出现破洞 → 保留边界边不折叠（boundary lock）。

### A9 程序化规则（L-System / 形状语法 / 元胞自动机）
**用在哪**：植物、树枝、城市街区、格栅纹样、复杂重复结构、纹理级细节。
- L-System：字符串重写 + 龟形解释器，生成分支结构。
- 形状语法：规则替换体块，生成建筑/布局。
- 元胞自动机：局部规则演化出全局图案（洞穴、裂纹、锈斑）。

```
公理: A
规则: A → A B ; B → A
迭代 4 次 → 分支结构，每段长度按 0.8 收缩、转角 ±25°
```
**要点**：随机要带种子（`seededRandom(seed)`），否则每次刷新都不一样，无法交付。
**失效**：分支爆炸 → 限深度（≤5）和子节点数（≤3）。

### A10 噪声族（Perlin / Simplex / Worley / FBM / Domain Warp）
**用在哪**：程序化纹理、地形、粗糙度变化、置换、云、锈迹。
- Perlin/Simplex：连续渐变噪声，做基础起伏。
- Worley（Cellular）：胞状，做皮革粒面、水面、石纹。
- FBM：多层噪声叠加（每层频率 ×2、幅度 ×0.5），做自然细节。
- Domain Warp：用噪声扰动噪声的坐标，做流体/大理石/云。

```js
const fbm = (p, oct = 4) => { let v = 0, a = 0.5, f = 1;
  for (let i = 0; i < oct; i++) { v += a * noise(p.x*f, p.y*f, p.z*f); f *= 2; a *= 0.5; }
  return v; };
```
**核心用法**：同一个噪声场驱动多个通道（粗糙度、AO、轻微色偏），才是「同一块表面」。各自独立噪声 = 材质分裂。
**失效**：高频噪点在远处闪烁（摩尔纹）→ 加 mipmap、降频率、或按距离淡出。

## B 材质与光照

### B1 PBR 五通道一致性
**用在哪**：所有需要「像真材料」的物体。
五通道：`color` / `roughness` / `metalness` / `normal` / `ao`。

三条一致性规则：
1. **metalness 是二元物理属性**：非金属 0、金属 1。中间值只出现在真的混合区（锈蚀、涂层剥落、镀层磨穿）。
2. **roughness 必须有空间变化**，且变化依据是成因（磨损处低、积灰处高、加工纹方向性）。
3. **normal 描述微观几何**，尺度要比 roughness 的变化更细，方向要与加工工艺一致（车削同心、拉丝单向、压铸皮纹随机）。

**失效**：全场景材质看起来一样 → 检查是不是所有材质共用了同一个 `MeshStandardMaterial` 实例只改了 color。

### B2 程序化贴图
**用在哪**：零素材条件下要真实感；需要可平铺、无版权风险的纹理。
- 用 `CanvasTexture` 在 2D canvas 上画：噪声 → 阈值 → 模糊 → 叠加。
- 关键：**从几何推导贴图**。凹槽位置该更暗（AO），凸缘该更亮（磨损），两者用同一张高度图派生。
- 平铺要无缝：噪声用 4D 采样或 `wrappingS = RepeatWrapping` + 边缘混合。

**失效**：贴图有明显接缝 → 用镜像平铺（`MirroredRepeatWrapping`）或把接缝藏在结构转折处。

### B3 IBL / PMREM 环境
**用在哪**：所有金属、玻璃、塑料的可信度来源。
零资产方案：`RoomEnvironment` → `PMREMGenerator` → `scene.environment`。
```js
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;
```
**要点**：环境光不是可选项，物理材质没有环境光一定读成塑料。
**失效**：环境过亮导致反差消失 → 调 `scene.environmentIntensity`（r18x 支持）或降曝光，不要靠加灯补。

### B4 阴影
**用在哪**：形体落地感、接触关系、层级。
- PCFSoft：默认，质量/成本平衡。
- VSM：软阴影，适合大面积柔光，但有漏光。
- CSM（级联）：大场景远近都清晰，成本高。
**网页级现实**：一张 2048 shadow map + `shadow.bias` 调 -0.0005 抗阴影痤疮，足够。
**失效**：阴影边缘锯齿 → 提高 mapSize 或改用接触阴影（见 B5）。

### B5 AO / 接触阴影
**用在哪**：物体与承托面之间必须有的暗部。
- 接触阴影（零成本）：物体下方一张径向渐变的透明面片，或 `ShadowMaterial` 平面。
- SSAO/GTAO：屏幕空间，成本中等，只用来收紧缝隙，不能整屏抹灰。
**要点**：AO 的作用是「让接触成立」，不是「让画面变脏」。
**失效**：AO 让画面发灰 → 降强度、只在缝隙生效，或直接改用接触阴影。

### B6 色彩管理
**用在哪**：每一次交付。
三条铁律：
1. 光照在线性空间算，线性→屏幕的转换**全程只做一次**。
2. 无后处理：渲染器做（`outputColorSpace = SRGBColorSpace` + `toneMapping`）。
3. 有后处理：交给链末输出 pass，同时把渲染器的 toneMapping 关掉。
4. 曝光在 tone mapping 之前调，不是之后加滤镜。
**失效**：画面整体发灰、白色发黄 → 检查是不是做了两次转换（渲染器 + 后处理各一次），这是最难查的一类 bug。

## C 运动与时间

### C1 插值
**用在哪**：所有过渡、展开、归位、悬停。
| 曲线 | 用途 | 公式要点 |
| --- | --- | --- |
| 线性 | 无意义，慎用 | 读起来像机器 |
| easeInOutCubic | 通用过渡 | `t<.5 ? 4t³ : 1-(-2t+2)³/2` |
| 指数响应 | 视觉参数平滑（阻尼感） | `v += (target-v)*(1-exp(-k*dt))` |
| 临界阻尼弹簧 | 需要质量感 | 必须收敛，且残余 < 1px 时强制归零 |

**要点**：视觉用指数响应，只有需要表现质量惯性才用弹簧。弹簧不收敛 = 肉眼看不见的抖动 + 一直耗电。
**失效**：运动看起来「廉价」→ 加一点点过冲与时长差异，不要全都同一条曲线。

### C2 编排（Beat Sheet + 状态机）
**用在哪**：装配演示、工序流程、原理讲解。
结构：
```
状态机：idle → intro → step1..N → summary → idle
每步: { enter(), update(t), exit(), duration }
时间轴: 全局 elapsed，各步按区间映射局部 t∈[0,1]
```
**要点**：必须能暂停、重播、单步；每步要有语义（接近/对准/插入/锁定/完成），不是若干 transform 各自动。
**失效**：动画看不出发生了什么 → 每个状态变化加一个「确认动作」（落位时轻微下压 + 停顿 200ms）。

### C3 IK（反向运动学）
**用在哪**：机械臂、腿部着地、手指抓握、装配对位。
- FABRIK：迭代拉线，简单稳定，适合多节链。
- CCD：循环旋转各关节，快但容易抖。
**要点**：先做「两骨解析解」（余弦定理），三节以上再上 FABRIK；限制每节角度范围，否则会出现反关节。
**失效**：手臂穿模 → 加关节角度上下限 + 末端目标不可达时降级为「尽力伸展」。

### C4 质点弹簧 / 布料 / Verlet
**用在哪**：布料、绳索、软管、旗帜、果冻感。
```
Verlet 积分（位置更新，无需速度变量）：
x_next = x + (x - x_prev) * damping + a * dt²
约束求解: 迭代 N 次把每段长度拉回 restLength
```
**要点**：约束迭代 3–8 次即可；顶点数控制在 20×20 以内（网页级）。
**失效**：爆炸/抖动 → 降 dt（固定步长 1/120 并插值）、加阻尼、限制最大位移。

### C5 群体（Boids）
**用在哪**：鸟群、鱼群、粒子集群、物流车辆。
三力：分离（避免碰撞）、对齐（速度趋同）、聚合（靠向中心）。
**要点**：空间哈希做邻域查询，否则 O(n²)；n ≤ 300 时 O(n²) 也能跑。
**失效**：群体糊成一团 → 提高分离权重、给个体速度差异。

### C6 路径跟随（弧长参数化）
**用在哪**：传送带物料、车辆、相机轨道、机械手轨迹。
```js
const u = curve.getUtoTmapping(0, distance / curve.getLength());
const p = curve.getPointAt(u);
```
**要点**：必须用弧长（`getPointAt`），否则拐弯处速度突变。
**失效**：物体在拐弯处「跳」→ 用切线与上方向做姿态对齐，并限制每帧转角。

### C7 机构运动学（工业重点）
**用在哪**：四连杆、齿轮、凸轮、传送带、机械手节拍。
| 机构 | 计算 | 用途 |
| --- | --- | --- |
| 四连杆 | 给定曲柄角，解两圆的交点得连杆位置 | 摆动机构、雨刷、活塞 |
| 齿轮副 | `ω2 = ω1 * z1/z2`，反向 | 减速箱、传动演示 |
| 凸轮 | 从动件位移 = f(凸轮角)，用位移表插值 | 阀门、间歇机构 |
| 曲柄滑块 | `x = r cosθ + √(l² - r²sin²θ)` | 冲压、内燃机 |

```js
// 四连杆：A 固定、AB 曲柄、BC 连杆、CD 摇杆
// 已知 A,B,C,D 与曲柄角 θ → B 点确定 → 求 C：以 B 为心半径 BC、以 D 为心半径 CD 的两圆交点
```
**要点**：用几何解而不是数值迭代，稳定且无漂移；两圆无交点说明连杆装不上，要标红提示并夹到极限位置。

## D 交互

### D1 射线拾取
**用在哪**：点击部件、悬停高亮、热点锚定。
```js
raycaster.setFromCamera(ndc, camera);
const hits = raycaster.intersectObjects(root.children, true);
```
**要点**：`root.children` 而不是 `scene.children`（排除地面与辅助物）；拾取前 `mesh.userData.pickRoot` 标记可拾取组。
**失效**：大场景卡 → 先做包围球粗判，或只在 pointerup 时拾取，不在 pointermove 每帧拾取。

### D2 轨道限位
**用在哪**：每个可旋转场景。
```js
controls.minPolarAngle = Math.PI * 0.12;
controls.maxPolarAngle = Math.PI * 0.62;   // 不许到地面以下
controls.minDistance = R * 1.6;
controls.maxDistance = R * 4.2;
```
**要点**：R = 主体包围球半径；距离与极角由 R 推导，不填死值。禁用平移或限制在包围盒内。
**失效**：能穿进物体内部 → 加 `minDistance` 与相机碰撞半径。

### D3 爆炸视图 / 剖切
**用在哪**：结构讲解、装配演示、内部展示。
- 爆炸：每个部件沿预设方向平移 `d = k * partIndex`，用父子组避免相对位移错乱。
- 剖切：`renderer.clippingPlanes` + 一个平面，配 `localClippingEnabled = true`；剖面内侧要用双面材质，否则看穿。
**要点**：爆炸要有顺序（由外到内），并保持视觉层级可读；剖切要跟着相机或固定方向，不要让用户困惑。
**失效**：剖切后内部全黑 → 内部补一层内壁（反法线壳）或给双面材质。

### D4 3D 标注
**用在哪**：教学、部件说明、工序说明。
实现：世界坐标 → 投影到屏幕 → 定位 DOM 标签；标签与锚点用一条引线连接。
```js
const p = obj.getWorldPosition(v).project(camera);
label.style.transform = `translate(${(p.x*0.5+0.5)*W}px, ${(-p.y*0.5+0.5)*H}px)`;
```
**要点**：标签要避让（同侧标签做纵向排布）；被遮挡时（射线检测）淡出，否则标签会飘在物体前面说谎。

### D5 状态切换
**用在哪**：多视图、多材质、多工序。
用普通对象 + 重渲染函数，不要引入框架。所有切换都要有过渡（0.2–0.4s），不要瞬切。

## E 工业与流程

### E1 节拍模型（Takt Time）
**用在哪**：产线可视化，必须让观者读懂「为什么这里堵」。
```
节拍 T = 可用工作时间 / 客户需求量
工位负荷 = 该工位作业时间 / T
瓶颈 = max(工位负荷)；产线产出 = 1 / max(工位作业时间)
```
**要点**：把负荷 > 1 的工位用醒目色标出，这是「看懂流程」的核心信息，比模型精细度重要一个数量级。

### E2 工序甘特 / 工位时间条
**用在哪**：多工位并行流程。
横向时间轴、纵向工位、色块=工序。用 2D 叠加在 3D 画面上（HUD 层），比在 3D 里画条更清晰。

### E3 物流路径
**用在哪**：AGV、传送带、物料流向。
曲线 + 弧长跟随（C6）；多车用排队模型避免穿模：维护每条路径的 `occupied` 区间。

### E4 布局比例
**用在哪**：车间、产线全景。
必须按真实尺度：通道宽度 ≥ 0.8m（单人）、设备间距按实际；人物 1.7m 作为尺度锚。缩放一致才能让人读出「这条线有多大」。

### E5 数据着色
**用在哪**：OEE、良率、温度、压力等指标映射到设备。
把指标映射到 `emissive` 强度或色相（连续量用顺序色阶，不要用彩虹）。必须在图例里写清映射规则，否则颜色是装饰。

## F 性能

### F1 实例化
**用在哪**：重复构件（螺栓、散热片、踏板、货箱、树）。
```js
const im = new THREE.InstancedMesh(geo, mat, count);
for (let i = 0; i < count; i++) { dummy.position.set(...); dummy.updateMatrix();
  im.setMatrixAt(i, dummy.matrix); }
im.instanceMatrix.needsUpdate = true;
```
**要点**：单个 draw call 搞定 N 个；需要单独拾取时用 `instanceId` 反查。
**失效**：需要每个实例不同颜色 → 用 `instanceColor`，不要拆成 N 个 mesh。

### F2 LOD 阶梯
**用在哪**：L2/L3、多物体场景。
```
LOD0 全模（距离 < 2R）
LOD1 60% 面（2R–6R）
LOD2 剪影/贴图面片（> 6R）
```
**要点**：切换点要有滞回（避免边界抖动）；LOD 组内对象必须共享材质才能合批。

### F3 剔除
视锥剔除（three.js 自动，但需正确包围盒）、遮挡剔除（大场景才做）、背面剔除（默认开）。
**要点**：自定义几何要手动 `computeBoundingSphere()`，否则剔除失效导致全量绘制。

### F4 合批
静态几何合并为一个 `BufferGeometry`（同材质），把 draw call 从 N 降到 1。适合墙体、地面、装饰构件。

### F5 GPU 粒子
用 `Points` + 自定义 shader，位置在顶点着色器里算，不要每帧在 CPU 更新 attribute。数量 1k–50k 可行；超过 50k 考虑 GPU 计算或降级。

### F6 分帧与预算
首帧预算：几何构建 ≤ 200ms、贴图生成 ≤ 100ms、编译着色器 ≤ 300ms。
重活（Marching Cubes、大贴图、模型解析）分帧或进 Worker，先给占位。

**降级阶梯（按顺序执行，每次只降一档）**：
1. 关后处理（bloom/AO/DOF）
2. 像素比 2 → 1.5
3. 阴影 mapSize 2048 → 1024，或关阴影改用接触阴影
4. 材质降级（`MeshPhysicalMaterial` → `MeshStandardMaterial`）
5. 减面 / 触发 LOD1
6. 关环境反射（environment → null）

**永远不要为了帧率牺牲交互响应**：卡顿比画质差更毁体验。
