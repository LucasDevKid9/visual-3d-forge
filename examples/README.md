# 示例

## planetary-gear-3d · 行星齿轮减速器

一个可运行的 D0 页面，用来验证整条管线而不是只验证"能出图"。

| 项 | 值 |
|---|---|
| 对象 | 单级行星齿轮减速器（NGW 型） |
| 尺度 | 模数 2 mm，太阳轮 18 齿、行星轮 21 齿、内齿圈 60 齿，齿宽 22 mm |
| 传动比 | i = 1 + 60/18 ≈ 4.33 |
| 构件 | 内齿圈、太阳轮+输入轴、3×行星轮（含铜衬套）、行星架+输出轴、承影面 |
| 交付形态 | D0（单文件 CDN），19 KB |
| 校验 | 18 项全过，0 警告（`--strict` 退出码 0） |

### 它演示了什么

- **IR 先行**：文件里 `const S = {...}` 是尺度表，所有几何由它派生，没有散落的魔法数字。
- **实例化**：60 个内齿、18 个太阳轮齿、每个行星轮 21 齿都是 `InstancedMesh`，总面数仅 ≈1,450。
- **材质不分裂**：机加工细纹只作用于 `roughnessMap`，颜色与法线不动；数据贴图设 `NoColorSpace`。
- **三光制**：主光定形体、补光留结构、冷轮廓光剥离背景；承影面只接阴影不显示自身。
- **传动按威利斯方程联动**：行星轮自转 = −(z_sun/z_planet)·θ，行星架 = θ·z_sun/(z_sun+z_ring)。
- **爆炸视图**：滑块只改位移不改几何；行星轮径向分离，避免插进齿圈壁。

### 怎么跑

直接双击 `行星齿轮减速器.html`（需联网取 CDN）。要离线：

```bash
python3 scripts/bundle.py --src "examples/planetary-gear-3d/行星齿轮减速器.html" \
  --out out/planetary-offline.html --vendor assets/vendor
```

> 注意：`bundle.py` 的 `--src` 需是 importmap 指向本地 vendor 的 D2 页面；
> 本示例是 D0，先按 `references/00-delivery-modes.md` 换档，或直接改用
> `assets/scaffold/forged-scene.vendor.html` 作起点。

### 已知不足

- 齿形用矩形块近似，不是渐开线；近看能看出是"方块齿"。
- 行星架省略了下压板（为了不遮挡内部），真实结构应有。
- 拾取说明卡只在点击时出现，移动端首次点击可能被当作拖拽起点。
